# TAILHS Webapp Final Project - Simulating DTI in novel Drugs
This project's goal is to somewhat accurately simulate and predict Drug-Target Interactions, where we use a neural network trained on data standardized in the field to show the affinity coefficient between a drug and its desired interaction site.
Note: This project has been deprecated and moved over to hugging face spaces for easier API integration. Here's the link: https://huggingface.co/spaces/theoneandonlyboogel/TAILHS-Webapp-Project
